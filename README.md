# PF1 自动治疗（pf1-auto-heal）

给 Foundry VTT 的 **Pathfinder 1e** 系统补上最后一步：**释放治疗法术时，自动把治疗量加到选中的目标身上。**

---

## 为什么做这个

PF1e 里治疗法术掷完骰，治疗量只会出现在聊天栏。接下来你得手动打开目标角色卡 → 点「治疗」→ 输入数字 → 确认。一场战斗里这个动作要重复十几次。

这个模块把这步接上：掷完骰，血自己就回来了。

**没有其它模块提供同样功能。** `pf1-automate-damage`、`nevelas-automation-suite` 只给伤害/治疗按钮，仍需手点；社区宏仓库里只有一个单件魔杖宏。

---

## 功能一览

| # | 功能 | 默认 |
|---|---|---|
| 1 | 释放治疗法术自动应用治疗 | 开 |
| 2 | 目标必须在法术射程内 | 开 |
| 3 | 射程读不出来时的处理策略 | 按触碰处理 |
| 4 | 敌对目标弹窗确认 | 开 |
| 5 | 【精类遗孤 Fey Foundling】按骰数额外 +2/骰 | 开 |
| 6 | 玩家可治疗自己没有权限的角色卡（GM 代劳） | 自动 |

---

## 1. 自动应用治疗

**触发条件**：PF1 判定这是一次治疗动作（`actionType === "heal"` 或 `isHealing`），**并且你选了目标**。

- 选了目标 → 治疗
- 没选目标 → 什么都不做（不误伤、不误治）

**治疗方向**：模块给 `applyDamage` 传的是**负数**。PF1e 就是这么表示治疗的（`if (this.isHealing) value = -value;`），所以走的是系统正规通道，能被各种天赋、伤害减免、非致命伤害规则正常处理。

---

## 2. 范围检查

目标必须在射程内才会被治疗。

**支持的射程写法**

| 写法 | 换算 |
|---|---|
| `touch` / 触碰 | 5 尺 |
| 固定数值 `25 ft.` / `30 ft.` / `100 ft.` | 原值 |
| `close` | 25 尺 + 5 尺 / 2 级 |
| `medium` | 100 尺 + 10 尺 / 级 |
| `long` | 400 尺 + 40 尺 / 级 |
| `personal` | 0 尺 |
| `unlimited` / `sight` | 不限 |

**施法等级从哪来**：从角色的**法术书**读（`system.attributes.spells.spellbooks.<book>.cl`），按法术所属的 spellbook 取，取不到再用正在使用的法术书，最后才退回 HD。

> 这一条踩过坑：PF1e 的 Actor 上**没有** `attributes.cl` 这个字段。早期版本读它，永远得到 NaN，于是 `close` 一律被当成 25 尺，范围检查形同虚设。

**容差**：射程 ≤5 尺（触碰类）时额外给一格容差。网格上两个人贴着站，中心点距离可能是一格而不是 0，不给容差就会出现「明明我摸得到却治不了」。

---

## 3. 射程读不出来时怎么办

有些法术条目没填射程数据（射程写的是「见描述」之类）。这时按设置处理：

| 选项 | 行为 |
|---|---|
| **按触碰处理（5 尺）** ← 默认 | 当作 5 尺，偏保守 |
| 放行（不检查距离） | 只要选中就治 |
| 拦下（不治疗） | 干脆不治 |

默认选保守的那个：**宁可少治，不要凭空治到地图另一头。**

---

## 4. 敌对目标确认

目标是敌对阵营时，先弹窗问一句。

| 目标阵营 | 行为 |
|---|---|
| 敌对（hostile） | **弹窗确认**（默认选中「取消」） |
| 友好（friendly） | 直接治疗 |
| 中立（neutral） | 直接治疗 |

施法者是中立阵营、目标是友好 → 直接治疗（不会因为阵营不同就拦你）。

## 5. 【精类遗孤 Fey Foundling】

> 专长原文：无论何时你受到魔法治疗时，**每骰**会额外治疗 2 点。

判定依据是**骰数**，不是总量。所以：

| 治疗掷骰 | 骰数 | 实际治疗 |
|---|---|---|
| `2d8+5` | 2 | 掷出值 **+4** |
| `3d8+5` | 3 | 掷出值 **+6** |
| `1d8+9` | 1 | 掷出值 **+2** |

`2d8+5` 掷出 13 和 `1d8+9` 掷出 13 总量一样，但前者 +4、后者 +2 —— 这就是为什么必须数骰子。

**专长识别**

按名字匹配，忽略大小写、空格、连字符、括号：

- `Fey Foundling`
- `精类遗孤`
- `精类遗孤 Fey Foundling`
- `fey  foundling`

只认 `type === "feat"` 的条目，避免同名的武器或物品误判。

**骰数从哪数**（三级回退）

1. ChatAttack 上的伤害骰（`damage.rolls[].terms[]`）—— 最准
2. 聊天消息的骰（`message.rolls[].terms[]`）
3. 伤害公式文本（`"2d8+5"` → 2）

统计时**排除 d20**。聊天消息里可能同时挂着触碰攻击的攻击骰，把 d20 当成治疗骰会凭空多 +2。

## 6. 跨权限治疗

**问题**：玩家不能修改自己没有权限的角色卡。Foundry 会静默丢弃写入，界面上什么反应都没有。

**做法**：按能力分三级。

```
① 是自己的卡 / 自己是 GM
   → 直接 applyDamage

② 别人的卡，且 socketlib 可用
   → socketlib.executeAsGM(...)，由 GM 客户端执行

③ 别人的卡，socketlib 不可用
   → 发一条只有 GM 看得见的私密聊天消息，GM 收到后执行并删除该消息
```

**为什么要有第 ③ 条**：`module.json` 里的 `"socket": true` 是 **FVTT 服务器启动时**读取的。只刷新浏览器，这个标记不生效，socketlib 会拒绝注册（它自己的报错原文：*"simply reloading your browser won't do"*）。而聊天消息走的是 Foundry 原生文档同步，**不需要任何 socket 声明**，刷新即可用。

**多 GM 时**：只让主 GM（`game.users.activeGM`）处理，避免两个人同时治疗导致回血翻倍。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用自动治疗 | **开** | 总开关 |
| 检查法术范围 | **开** | 关掉后只要选中目标就治疗，不判距离 |
| 射程读不出来时怎么办 | **按触碰处理（5 尺）** | 可选：按触碰 / 放行 / 拦下 |
| 对敌对目标弹窗确认 | **开** | 关掉则敌对目标也直接治疗 |
| 检测【精类遗孤 Fey Foundling】 | **开** | 关掉则不检测该专长 |
| 输出【精类遗孤】判定日志 | 关 | 打印是否命中、几颗骰、加多少 |
| 输出诊断日志 | 关 | 打印射程解析与距离判断过程 |

## 治疗量是怎么算的

四级回退，取到就停：

1. `ChatAttack.totalDamage` —— PF1 系统自己算好的总和，最可靠
2. 逐段 `damage.rolls[].total` 求和
3. 聊天消息的 `message.rolls[].total`
4. 用 `action.damage.parts[].formula` 现场掷一次

## 怎么确认它在工作

打开浏览器控制台（F12），应该看到：

```
pf1-auto-heal | 已加载
pf1-auto-heal | v0.3.0 就绪 | 模块 socket 标记: 已生效 | GM 代劳通道: socketlib
```

治疗一次后：

```
pf1-auto-heal | 已治疗 某角色 +18
pf1-auto-heal | 已治疗 某角色 +22（基础 18，精类遗孤 +4）
```

跨权限治疗时：

```
pf1-auto-heal | GM 某某 代 玩家甲 治疗 某角色 +18
```

## 常见问题

**Q：放了治疗法术，血没回。**
开「输出诊断日志」，再放一次，看控制台：
- 没有 `pf1-auto-heal |` 任何输出 → 模块没加载，检查启用状态
- 有 `治疗量解析失败` → 这个法术的治疗数据格式没被识别
- 有 `射程解析失败` → 射程读不出来，看当前策略设置
- 什么都没有，但有一个对话框 → 目标敌对，等你在弹窗里点「治疗」

**Q：给别人的卡治疗没反应。**
- 确认有 GM 在线（跨权限必须有人在）
- 看控制台是 `GM 代劳通道: socketlib` 还是 `聊天消息`
- 显示 `聊天消息` 也能用，只是多绕一步

**Q：显示了治疗成功，但玩家看不到血条变化。**
玩家对那张卡没有观察权限时，**数据确实改了，但界面上看不到**。让 GM 确认一下，或者在权限里给观察权限。

**Q：精类遗孤没生效。**
先开「输出【精类遗孤】判定日志」。如果连「命中」那行都没有：
- 专长名字对不上 → 检查是不是 `feat` 类型、名字里有没有生僻写法
- 骰数没数出来 → 这个法术的治疗公式解析不出骰子

**Q：能不能群疗一次治多个目标？**
可以。选中多个目标会逐个治疗，每个目标单独判定射程、敌对、精类遗孤。

## 已知限制

- **GM 必须在线**才能治疗自己没有权限的角色卡。
- **只处理标准治疗动作**（`heal` 类型）。用自定义宏或直接改属性来回血不会触发。
- **精类遗孤只实现了「每骰 +2 治疗」这一条效果**。专长的另外两条（对抗死亡效果豁免 +2、受寒铁武器伤害额外 +1）不属于治疗范畴，没有实现。
- **骰数解析不出来时不加精类遗孤加成**。按骰数加的前提是先知道几颗骰；纯固定数值的治疗不会触发。
- **依赖网格测距**。没有网格的场景（ theater of the mind ）距离可能不准。

## 安装

1. 把 `pf1-auto-heal` 文件夹放进 `Data/modules/`
2. 在「管理模块」里启用
3. **重启 FVTT 服务器**（`module.json` 里有 `"socket": true`，这个标记只在服务器启动时读取）
   - 之后单纯改代码只需 Ctrl+F5 刷新
4. 建议同时启用 **socketlib**（有它就走更可靠的 GM 代理通道，没有则自动用聊天消息通道）

**系统要求**：Pathfinder 1e（`pf1`）11.0+ ｜ Foundry VTT 11–13

## 技术备注

| 项 | 说明 |
|---|---|
| 触发钩子 | `pf1PostActionUse` |
| 目标来源 | 优先 `actionUse.shared.targets`，退回 `game.user.targets` |
| 治疗方向 | `applyDamage(-amount, {healing: true, ...})` |
| 射程字段 | `action.range` → `item.system.range` → `item.system.actions[].range` |
| 施法等级 | `system.attributes.spells.spellbooks.<book>.cl` |
| 测距 | `canvas.grid.measureDistance()` |
| 跨权限 | socketlib → 聊天消息（whisper + blind） |
